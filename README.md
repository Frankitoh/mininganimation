# Hytale Block Animations (Forge 1.12.2)

Mod **solo cliente** (RetroFuturaGradle):
- Al picar un bloque (cubo completo y opaco) se mueve con squash & stretch como en Hytale.
- Al romperlo, el bloque se achica hasta el tamaño del item.
- Config in-game: *Mods → Hytale Block Animations → Config* (velocidad, intensidad, duración, toggles).

## Compilar / probar
- `./gradlew runClient` para probar
- `./gradlew build` → jar en `build/libs/`
