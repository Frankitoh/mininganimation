# Hytale Block Animations (Forge 1.12.2)

Mod **solo cliente** (RetroFuturaGradle):
- Al picar un bloque (cubo completo y opaco) se hunde levemente con cada golpe (más sutil sin la herramienta correcta).
- Config in-game: *Mods → Hytale Block Animations → Config* (velocidad e intensidad).

## Compilar / probar
- `./gradlew runClient` para probar
- `./gradlew build` → jar en `build/libs/`

> Requiere **MixinBooter** (1.12.2) instalado en la carpeta `mods`.
